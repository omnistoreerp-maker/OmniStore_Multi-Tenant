# سيناريوهات UAT للعميل

## إضافة منتج

راجع البيانات المطلوبة والسعر والتكلفة والكمية باستخدام بيانات تجريبية.

## فاتورة شراء

راجع المورد والأصناف والكميات والتكلفة وتوقف قبل الحفظ الفعلي.

## فاتورة بيع

راجع العميل والأصناف والسعر والخصم والإجمالي وتوقف قبل الحفظ الفعلي.

## نقطة البيع

ابحث عن منتج، راجع السلة والدفع، ولا تتمم البيع.

## مراجعة المخزون

راجع الكميات والحركات والتحذيرات دون تسوية أو تحويل فعلي.

## مراجعة التقارير

اختبر البحث والفلاتر ومعاينة الطباعة والتصدير.

## مركز معاينة العمليات

راجع الأثر المحاسبي والمخزني المتوقع؛ المعاينة محاكاة فقط.

## مركز جاهزية الترحيل

راجع الأخطاء والتحذيرات دون إصلاح أو ترحيل.

## الفحص النهائي

راجع الحسابات والمخزون والصلاحيات وموانع الترحيل.

## ملاحظات العميل

أضف ملاحظة مؤقتة وصنّفها ثم انسخ أو صدّر المعاينة قبل إعادة تحميل الصفحة.
