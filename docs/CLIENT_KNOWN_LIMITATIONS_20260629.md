# حدود نسخة العميل الحالية

- النسخة UAT/Beta وليست تشغيلًا ماليًا نهائيًا.
- مراكز المعاينة محاكاة فقط.
- لا يتم حفظ أو ترحيل قيود محاسبية فعلية.
- لا يتم حفظ أو ترحيل حركات مخزون فعلية من مراكز المعاينة.
- القوائم المالية الرسمية غير مفعلة بعد.
- ملاحظات UAT مؤقتة وتختفي عند إعادة تحميل الصفحة.
- يجب اختبار الشاشات ومسارات العمل والتقارير والتنقل وسهولة الاستخدام.
- يجب جمع ملاحظات العميل بعد العرض ومراجعتها قبل الاعتماد.
