# Phase 32 Recovery Flow

## Backup

Eight previews cover Local, Cloud, Database, Assets, Configuration, Users, Licenses, and Full Workspace. Each preview enumerates content, estimates size, calculates the intended verification steps, and reports zero writes.

## Restore

`Backup validation → Manifest comparison → Missing-file detection → Conflict detection → Overwrite preview → Time/size estimate → Future authorized executor`

The last executor does not exist in Phase 32.

## Update and versions

Installed/latest version comparison, release notes, compatibility, required migration preview, backup requirement, rollback target, previous builds, installed builds, and upgrade history are represented without execution.

## Health

Recovery health covers backup age, storage usage, backup integrity, version integrity, migration integrity, and configuration integrity.
