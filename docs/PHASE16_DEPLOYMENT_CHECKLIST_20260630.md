# Phase 16 Deployment Checklist

- [ ] Confirm production URL, HTTPS certificate, and application scope.
- [ ] Confirm deployment owner and maintenance window.
- [ ] Verify `manifest.json`, all icons, and installability on target devices.
- [ ] Verify service-worker v22 activation and old-cache replacement.
- [ ] Run smoke tests on supported browsers and screen sizes.
- [ ] Validate offline application shell on the production origin.
- [ ] Confirm backup and non-destructive rollback procedure.
- [ ] Confirm customer training and support contacts.
- [ ] Record known limitations.
- [ ] Obtain customer UAT sign-off before activation.

This checklist does not deploy or change the application.
