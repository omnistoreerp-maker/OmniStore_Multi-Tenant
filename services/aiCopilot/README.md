# Phase 35 AI Business Copilot

The Copilot is a deterministic, local, read-only assistant over an injected ERP snapshot.

- Natural-language intent detection in Arabic and English.
- Smart search for stock, sales, invoices, customers, profit, suppliers, and movement.
- Advisory sales, inventory, accounting, purchase, customer, and supplier insights.
- Executive, knowledge, analysis, and training summaries.
- Context-aware chat for reports, errors, pages, products, backup, and training.
- Safety validation rejects execution, delete, insert, update, post, save, deploy, restore, activate, and suspend commands.

There is no external AI API, API key, fetch, SQL, Supabase client, write operation, posting, or business-module import.
