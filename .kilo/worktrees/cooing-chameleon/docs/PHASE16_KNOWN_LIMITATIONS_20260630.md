# Phase 16 Known Limitations

- Accounting and inventory posting remain simulation-only.
- Phase 11 accounting SQL files remain draft designs and were not executed.
- UAT checks detect availability; they do not perform destructive end-to-end transactions.
- Customer training, device/browser testing, and formal sign-off require human participation.
- Performance values are readiness budgets, not laboratory benchmarks.
- Offline behavior must be confirmed on the final HTTPS deployment origin.
- Exported UAT JSON is a browser download and is not stored by OmniStore.
