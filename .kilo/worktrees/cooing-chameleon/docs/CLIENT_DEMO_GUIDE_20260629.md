# دليل عرض OmniStore ERP للعميل

## طبيعة النسخة

هذه نسخة **UAT/Beta** مخصصة للتجربة وقبول العميل قبل التشغيل النهائي.

- مراكز المعاينة محاكاة فقط.
- لا يوجد ترحيل محاسبي فعلي.
- لا يوجد ترحيل مخزون فعلي.
- القوائم المالية الرسمية غير مفعلة بعد.

## ترتيب العرض

1. اشرح لوحة التحكم والتنقل.
2. راجع المنتجات والبحث والفلاتر.
3. اشرح مسار الشراء والبيع ونقطة البيع دون حفظ عملية فعلية.
4. راجع المخزون والتقارير.
5. افتح مركز معاينة العمليات ومركز جاهزية الترحيل والفحص النهائي.
6. سجّل ملاحظات العميل مؤقتًا بعد العرض.
7. راجع قائمة التدريب وحدود النسخة ونموذج الاعتماد.

يجب على العميل اختبار الشاشات ومسارات العمل والتقارير والتنقل وسهولة الاستخدام.
