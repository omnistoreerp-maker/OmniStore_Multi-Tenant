# Phase 31 Self-Managed Platform

This isolated package unifies platform administration as read-only snapshots and workflow previews.

- Customer directory, search, status, plan, workspace, contact and usage metadata.
- Thirteen customer action planners; none has an executor.
- Twelve monitoring signals, eight notification groups, jobs and disabled workers.
- Six automation schedules represented as non-persistent plans.
- Nine-step zero-touch onboarding workflow preparation with zero Auth, Workspace, SQL, email, license or deployment execution.
- Seven read-only report builders.

The package has no Supabase, SQL, network, localStorage, posting, provisioning, deployment, licensing, Accounting, Inventory, POS, Sales or Purchases dependency.
