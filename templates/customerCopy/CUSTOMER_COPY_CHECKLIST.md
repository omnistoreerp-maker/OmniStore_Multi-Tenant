# Customer Copy Checklist

- [ ] استخدم مجلدًا جديدًا وفارغًا.
- [ ] لا تعدّل المشروع الرئيسي.
- [ ] املأ قوالب الشركة والهوية والعميل في النسخة الجديدة فقط.
- [ ] راجع نوع النشاط والعملة واللغة.
- [ ] احتفظ بشارات UAT/Beta والمعاينة الآمنة.
- [ ] شغّل جميع الاختبارات.
- [ ] راجع سيناريوهات العرض والتدريب والحدود.
- [ ] وثّق Snapshot وخطة Rollback.
- [ ] لا تنفذ SQL أو Supabase أو ترحيلًا فعليًا أثناء إنشاء النسخة.
